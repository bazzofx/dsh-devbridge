Features

Everything the extension does — nothing it shouldn't.

Point & click capture

Hover highlights the real element on the page; one click captures it. No more describing “that button at the bottom”.

Exact references

Every capture carries a verified unique CSS selector, its XPath and the visible text — so the agent knows precisely what you mean.

Tiny payloads

One compact JSON per review — URL, selector, XPath, text, comment. No HTML dumps, no duplication, fewer tokens.

Straight into Harness

Click Send to Harness chat and the capture is typed and submitted into your local chat — default 127.0.0.1:3080 — for you.

Local-first & private

No network requests, no tracking, no account. Captures stay in your browser’s local storage until you choose to send them.

History & re-send

Every capture is saved in the popup — re-send, copy as JSON, or download as Markdown whenever you like.

Configurable Harness port

Harness not running on the default port? Change it once under Settings (⚙ in the popup) and every send finds your chat there.

Master prompt on every send

Add standing instructions in Settings — e.g. “always verify the selector before editing code” — and they are prepended to every capture you send to Harness.

How to use

From page to Harness chat in four clicks.

  1. Install Dev Bridge for DSH from the Chrome Web Store (or load it unpacked during development).
  2. Open any website you want to review — your own app, a live page, anything.
  3. Pick — press Alt+Shift+E, or click the toolbar icon and choose Pick element on this page. Hover highlights the element; click it.
  4. Review — type your comment and press Send to Harness chat.

What lands in your Harness chat:

{
  "url": "https://example.com/page",
  "selector": "button#submit[data-testid=\"buy-now\"]",
  "XPath": "//button[@id='submit']",
  "Text": "Buy Now",
  "comment": "Move this button above the search bar."
}

The agent verifies the selector on that URL before touching any code — and asks you if it is ever ambiguous.

Privacy policy

Short version: this extension collects nothing and transmits nothing over the internet.

What we collect

Nothing. No personal data, no browsing history, no analytics, no advertising, no accounts.

Where captures live

Captures stay in chrome.storage.local on your device. They only travel to your locally running DeepSeek Harness at 127.0.0.1:3080 — your own machine — and only when you press Send.

Permissions, in plain terms

activeTab works only while you use the picker; loopback host access reaches only 127.0.0.1:3080; storage, scripting and clipboardWrite power the local list, on-demand picker and Copy button.

Network & third parties

The extension performs no network requests and loads no remote code. No third-party SDKs. Loopback stays on your machine.

Full details: privacy-policy.html (standalone page, ready to host for the Chrome Web Store).
